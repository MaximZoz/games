# Zozu Games — логотип

Знак читается в два шага:

1. Пиджак, рубашка и контур галстука.
2. Минималистичное НЛО спускается к горной гряде.

Две тонкие линии начинаются у НЛО, рисуют контур галстука и заканчиваются
на вершинах двух гор. От вершин отдельная непрерывная линия очерчивает
силуэт рубашки. Внутри добавлены чёткий воротник, планка, три пуговицы
в стиле огней НЛО и горный узор.

| Роль | Цвет |
|------|------|
| Фон холстов и холмов-рубашки | `#E8ECF4` (`surfaceUnified`) |
| Пиджак (squircle) и линии-стрелки | `#6366F1` → `#8B5CF6` |
| Заливка НЛО | `#1E1B4B` |

Белый цвет не используется.
