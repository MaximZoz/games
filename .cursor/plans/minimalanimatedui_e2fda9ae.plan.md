# План: Minimalist Animated UI (Flutter, multi-platform)

## Что уже сделано

- **Адаптивный AppShell:** `lib/ui/responsive.dart` (брейкпоинт 700px), на узких экранах — нижняя навигация (`NavigationBar`), на широких — боковой `NavigationRail`, общий тулбар и градиентный фон. Плавный переход между экранами (fade-out → fade-in). Логин/выход всегда видны в тулбаре.
- **Маршруты и заглушки экранов:** профиль, друзья, турниры, игры, инвентарь, достижения, настройки, монеты — пункты в навигации.
- **Дизайн-токены:** `AppColors`, `AppRadius`, `AppSpacing`, `AppDurations` в `app_theme.dart`. Тема (light/dark) — не делаем пока. Поля ввода без заливки (outline-стиль).
- **Профиль (полностью готов):**
  - Просмотр: аватар, ник, возраст + склонение (год/года/лет) + иконка пола, «о себе».
  - Редактирование: форма в карточке, закрытие кликом вне карточки, красный ✕ в углу.
  - Кнопка «Сохранить» заблокирована если изменений нет; разблокируется после правок.
  - Валидация: логин (латиница+цифры+`_`, макс. 10), возраст (1–111, только цифры), «о себе» (макс. 100 символов, защита от управляющих символов).
  - 12 пресетов аватара (иконки лиц м/ж), загрузка своего фото (base64), буква-заглушка.
  - Аватар кешируется — нет мерцания при наборе текста; декодирование base64 в отдельном isolate.
  - Сохранение на сервер (`PUT /api/profile`); ошибки: «логин занят», сетевые, общие — в разных местах UI.
- **Бэкенд профиля (готов):**
  - Миграция `004_add_profile_fields`: поля `age`, `gender`, `about`, `avatar_kind`, `avatar_value` в таблице `users`.
  - `PUT /api/profile` — обновление всех полей, проверка уникальности `display_name`.
  - `GET /api/me`, `/api/auth/register`, `/api/auth/login` — возвращают расширенный `UserResponse` с полями профиля.
- **Экран администратора (готов):**
  - Список всех пользователей: аватар (фото/пресет/буква), email, ник, бейдж «Админ».
  - Блок профиля: возраст, пол (иконка + цвет), «о себе» — отображается если заполнено.
  - Действия: назначить/снять админа, сбросить пароль, удалить пользователя.
  - Адаптивный layout: grid на широких экранах, list на узких.
- **Обработка ошибок:** сетевые ошибки (`ClientException`) — понятное сообщение на экране логина и главной. Ошибки сохранения профиля отображаются в баннере над кнопкой «Сохранить».

## Цели

- Минималистичный UI с аккуратными микро-анимациями, без визуального шума.
- Полная адаптивность: телефоны/планшеты/десктоп/веб (узкие/широкие экраны).
- Консистентная дизайн-система и единый подход к навигации/состояниям/ошибкам/загрузкам.
- Поддержка **светлой/тёмной темы** и переключателя.

## Опорная архитектура UI

- **Навигация**: `go_router` + общий `AppShell` (уже есть) и адаптивная навигационная хрома:
  - Узкие экраны: `BottomNavigationBar` (или `NavigationBar`).
  - Широкие экраны: `NavigationRail`/боковое меню.
  - Точка принятия решения по брейкпоинтам: один utility (например, `lib/ui/responsive.dart`).
- **Состояние**: Riverpod (уже используете). Для UI-слоёв — “controller/provider per feature”, UI без бизнес-логики.
- **Дизайн-система**: расширить текущий `lib/ui/`:
  - Токены: цвета/типографика/радиусы/интервалы/тени/времена анимаций.
  - Семантические роли цветов (surface, onSurface, accent, danger, success) для light/dark.
- **Анимации**: единые пресеты (`AppDurations`, curves), применять точечно:
  - `AnimatedSwitcher`, `AnimatedSize`, `Fade/Scale/Slide` для переходов состояний.
  - Лёгкие hover/focus эффекты для web/desktop (через `InkWell`/`MouseRegion`).

## Экраны (порядок реализации)

### 1) Профиль

- Экран: аватар/ник/уровень/стата/баланс/монеты.
- Редактирование: модалка/отдельный экран.
- Состояния: skeleton/shimmer, empty, error.

### 2) Друзья

- Список друзей, поиск, заявки (входящие/исходящие).
- Карточка друга (мини-профиль), действия (принять/отклонить/удалить).

### 3) Турниры

- Листинг турниров (карточки), фильтры/сегменты (активные/завершённые/мои).
- Детальная: описание, правила, призы, таблица.

### 4) Предметы (Инвентарь)

- Сетка/список с адаптивом (на широких — grid с `maxCrossAxisExtent`, на узких — list).
- Детальная предмета, экипировка/использование (UI).

### 5) Достижения

- Каталог достижений, прогресс.
- Анимация получения (баннер/конфетти лайтово, без тяжёлых эффектов по умолчанию).

### 6) Настройки

- Переключатель темы (light/dark/system), язык (если нужен), уведомления, аккаунт.

### 7) Игры

- Каталог мини-игр (карточки), экран запуска.
- Экран результата и история результатов (UI).
