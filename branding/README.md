# Zozu Games — логотип

Ровно **3 цвета**:

| Роль | Hex | Откуда |
|------|-----|--------|
| Фон | `#E8ECF4` | `AppColors.surfaceUnified` (+ лёгкий градиент к `#E0E7FF`) |
| Стрелки / линии | `#6366F1` → `#8B5CF6` | `BrandAccentHairline` (горы, рубашка, контур галстука — всё связано) |
| Заливка | `#1E1B4B` | галстук + корпус НЛО |

НЛО минималистичная в двух из этих цветов (заливка + акценты линий).

Чтение:
1. рубашка + галстук + тарелка-узел;
2. горы + НЛО (линии гор сходятся в пик вместе с остриём галстука).
