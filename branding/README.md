# Zozu Games — логотип

Знак читается в два шага:

1. Пиджак, рубашка и галстук.
2. Минималистичное НЛО спускается к горной гряде.

Две тонкие линии в стиле `BrandAccentHairline` идут от НЛО, очерчивают
галстук и сходятся в вороте; затем продолжают линию холмов-рубашки.

| Роль | Цвет |
|------|------|
| Фон холстов и холмов-рубашки | `#E8ECF4` (`surfaceUnified`) |
| Пиджак (squircle) и линии-стрелки | `#6366F1` → `#8B5CF6` |
| Заливка НЛО и галстука-гор | `#1E1B4B` |

Белый цвет не используется.
