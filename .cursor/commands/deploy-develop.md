Деплой ветки `origin/develop` на Fly из этого репозитория.

Действия:

1. Проверь, что файл `deploy.cursor.env` существует в корне проекта.
2. Запусти скрипт:
   - Linux/macOS: `./launcher/deploy_develop.sh`
   - Windows PowerShell: `.\launcher\deploy_develop.ps1`
3. Покажи краткий результат:
   - успешно/неуспешно;
   - если успешно — URL приложения;
   - если ошибка — 1–2 конкретных шага для исправления.

Требования:
- отвечай на русском;
- не предлагай ручной деплой, если скрипт можно запустить автоматически;
- если отсутствует `fly`/`flyctl` или `deploy.cursor.env`, сначала чётко сообщи, чего не хватает.
