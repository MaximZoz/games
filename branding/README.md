# Zozu Games — логотип

Полностью линейный знак читается в два шага:

1. Пиджак, рубашка и контур галстука.
2. Минималистичное НЛО спускается к горной гряде.

Две непрерывные линии в стиле `BrandAccentHairline` начинаются у НЛО,
рисуют контур галстука и без разрывов переходят в горы и ворот рубашки.
Линии не пересекаются, тёмная заливка галстука отсутствует.

| Роль | Цвет |
|------|------|
| Фон холстов и холмов-рубашки | `#E8ECF4` (`surfaceUnified`) |
| Пиджак (squircle) и линии-стрелки | `#6366F1` → `#8B5CF6` |
| Заливка НЛО | `#1E1B4B` |

Белый цвет не используется.
