# Если https://multigameszozu.fly.dev/ не открывается

## 1. Статус машин

В терминале из корня проекта:

```powershell
fly status --app multigameszozu
```

- **Stopped** — машина выключена (например, из‑за scale to zero). Первый запрос может идти 30–60 секунд, пока она запустится; обнови страницу и подожди.
- **Started** — машина работает; тогда смотри логи (шаг 2).

## 2. Логи приложения

```powershell
fly logs --app multigameszozu
```

Убедись, что есть строки:
- `Postgres: connected`
- `MultiGames server listening on http://localhost:8080` или `:8080`
- Нет повторяющихся падений и `exit code 1`

Если видишь падения или ошибки — пришли последние 20–30 строк логов.

## 3. Проверка API с твоего ПК

В браузере или в PowerShell:

```powershell
Invoke-WebRequest -Uri "https://multigameszozu.fly.dev/api/start" -UseBasicParsing
```

Должен вернуться статус 200 и тело `go start`. Если ошибка (таймаут, 502, connection refused) — приложение не принимает запросы.

## 4. Машина всё время Stopped

Если в `fly status` машина **Stopped** и не поднимается при открытии сайта:

```powershell
fly scale count 1 --app multigameszozu
```

Так ты заставишь держать одну машину всегда включённой (будет небольшой расход).

## 5. Перезапуск

Если логи выглядят нормально, но сайт не открывается:

```powershell
fly apps restart multigameszozu
```

Подожди 1–2 минуты и снова открой https://multigameszozu.fly.dev/

## 6. «Слишком много перенаправлений» (redirect loop)

- Открой сайт в **режиме инкогнито** (Ctrl+Shift+N) или в другом браузере.
- Очисти **cookies** для `multigameszozu.fly.dev`: F12 → Application → Cookies → удалить все для этого сайта.
- Проверь, открывается ли напрямую: https://multigameszozu.fly.dev/api/start (должна быть строка `go start`).

## 7. Доступ из РФ: не открывается или таймаут

Возможные причины:
- **Блокировки/ограничения** доступа к Fly.io или к части зарубежного хостинга у провайдера.
- **Долгий холодный старт** — машина была выключена (scale to zero), первый запрос ждёт 30–60 секунд; браузер может показать таймаут.

Что попробовать:
1. **VPN** — включи VPN (любая страна: Нидерланды, Германия и т.д.) и открой https://multigameszozu.fly.dev/ Если через VPN открывается — проблема в доступе из РФ.
2. **Другая сеть** — открой с телефона через **мобильный интернет** (не Wi‑Fi), или с другого провайдера.
3. **Машина всегда включена** — тогда не будет холодного старта:
   ```powershell
   fly scale count 1 --app multigameszozu
   ```
   Одна машина будет работать постоянно (небольшая плата).
4. **Проверка с твоего ПК** — в PowerShell:
   ```powershell
   Invoke-WebRequest -Uri "https://multigameszozu.fly.dev/api/start" -UseBasicParsing
   ```
   Если здесь таймаут или ошибка соединения — запросы до Fly.io с твоего интернета не доходят.

Если с VPN или с мобильного всё открывается, а с домашнего нет — это ограничения провайдера/сети. Варианты: пользоваться через VPN; развернуть приложение на VPS/хостинге в РФ или в стране с нормальным доступом из РФ.

---

После выполнения шагов 1 и 2 пришли вывод `fly status` и последние строки `fly logs` — по ним можно точнее сказать, в чём причина.
