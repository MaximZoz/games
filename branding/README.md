# Zozu Games — логотип

Оптическая двусмысленность в духе fly.io:

- **с первого взгляда** — пиджак, белая рубашка (V-вырез) и галстук;
- **если присмотреться** — воздушный шар над горами внутри силуэта галстука.

Цвета бренда: `#6366F1` → `#8B5CF6`, силуэт `#1E1B4B`, детали `#C7D2FE`.
