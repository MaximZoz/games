# Zozu Games — логотип

Оптическая двусмысленность в духе fly.io:

1. **С первого взгляда** — пиджак, белая рубашка (V-ворот) и галстук + две фирменные стрелки-линии из тулбара.
2. **Если присмотреться** — белый ворот читается как снежные пики, тёмный галстук — как ночное небо с инопланетной тарелкой.

Цвета: `#6366F1` → `#8B5CF6`, галстук `#1E1B4B`. Стрелки — тот же градиент, что `BrandAccentHairline`.
