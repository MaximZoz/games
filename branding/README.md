# Zozu Games — логотип

База — оптическая иллюзия как у референса «шар + горы = рубашка/галстук», в палитре приложения.

| Роль | Цвет |
|------|------|
| Фон холстов и холмов-рубашки | `#E8ECF4` (`surfaceUnified`) |
| Пиджак (squircle) | `#6366F1` → `#8B5CF6` |
| Заливка (НЛО + горы-галстук) | `#1E1B4B` |
| Стрелки (обводят горы и рубашку) | `#6366F1` → `#8B5CF6` (`BrandAccentHairline`) |

Шар заменён на минималистичное НЛО. Белого нет.
