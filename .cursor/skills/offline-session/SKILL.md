# Офлайн-сессия

Офлайн включается только явным выбором в настройках. Пропажа сети и медленный ответ сами режим не переключают: они показывают предложение (`shouldOfferOffline` в `client/lib/core/offline_mode_provider.dart`). Не делай `isOffline` равным `!hasNetwork`.

Онлайн-партия при обрыве остаётся в Redis. Этот skill про локальный стол с ботом и про экран, который читает последний снимок, пока режим включён.

## Где лежит

| Что | Файл |
|-----|------|
| Режим и probe сети | `client/lib/core/offline_mode_provider.dart`, `offline_reachability.dart` |
| Снимок магазина, инвентаря, наград, настроек | `client/lib/core/offline_disk_cache.dart` |
| Прогрев, пока есть сеть | `client/lib/core/offline_warmup.dart` |
| Живые локальные столы | `Offline*Registry` в `client/lib/games/**` |
| Общий сброс столов | `disposeAllOfflineGameSessions` в `client/lib/games/offline_session_hold.dart` |
| Очередь покупок | `client/lib/shop/pending_purchases.dart` |

`AppShell` заранее держит настройки только крестиков, дурака и покера. Прогрев пишет на диск те же три. Остальные игры в офлайне открываются на сохранённом снимке, только если их провайдер уже успел загрузиться онлайн.

## Новая локальная партия

1. Сессия и реестр по образцу `client/lib/games/chess/chess_offline_session.dart`: id с префиксом `offline:<id>:`, `put` / `get` / `disposeAll` / `isOffline`.
2. Provider партии при таком id читает реестр и не ходит в HTTP. Смотри `chess_provider.dart`.
3. Репозиторий хода, сдачи и реванша для этого id вызывает сессию, не API.
4. Экран запоминает путь через `rememberGamesSessionPath`. Уход с крестика — `leaveGamesSession`, затем `dispose` своей сессии.
5. Добавь `disposeAll()` этого реестра в `disposeAllOfflineGameSessions`. Сейчас там нет `OfflineChessRegistry`: часы шахмат продолжают идти, если уход прошёл через общий сброс, а не через крестик шахматного экрана. Правка этого файла обязана включить и шахматы, и новый реестр.
6. Путь `/games/<id>/offline` уже понимает `GameRegistry.isActiveGamePath`, если дескриптор зарегистрирован. Отдельный роут не плоди.
7. Роутер в офлайне уводит с друзей, чатов и лобби крестиков (`client/lib/router.dart`). Чужое онлайн-лобби `/games/<id>/lobby/` так же не должно оставаться открытым и крутить API.
8. Ставки в офлайне скрыты. Покупка идёт через `buyOrQueue`: в очередь, не в прямой `buy`.

Стол живёт в памяти процесса. На диск из партии сейчас пишется только флаг «кто начинал» у крестиков. Не обещай сохранение доски после перезапуска, пока отдельно не попросили снимок партии.

## Настройки и снимок

Пока режим включён, `userGameSettingsProvider` читает `OfflineDiskCache` и пишет туда же. Неудачный запрос на сервер не повторяется сам. Выход в онлайн заново читает сервер и может затереть правку, сделанную без сети. Если меняешь этот путь, грязные настройки должны уехать на сервер до того, как прогрев перезапишет диск. Пустой ответ магазина не затирает уже сохранённый каталог (`saveShop`).

Друзей и чаты в офлайне не показывай пустым сетевым экраном: оболочка убирает эти вкладки.

## Проверка

```bash
cd client && flutter test test/offline_reachability_test.dart test/offline_disk_cache_test.dart
```

Плюс тест сессии той игры, которую трогаешь (`*_offline_session_test.dart`). В тесте общего сброса проверь, что `disposeAllOfflineGameSessions` вызывает реестр новой игры и `OfflineChessRegistry`.
