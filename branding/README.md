# Zozu Games — логотип

Двусмысленность:

1. **С первого взгляда** — пиджак и рубашка: два холма цвета фона приложения (`#E8ECF4`) рисуют силуэт рубашки; по центру НЛО и две изогнутые фирменные стрелки (`BrandAccentHairline`) складываются в намёк на галстук.
2. **Если присмотреться** — пейзаж: холмы + летающая тарелка.

Белого нет: холмы и подложка — `AppColors.surfaceUnified` (`#E8ECF4`). Пурпур пиджака — `#6366F1` → `#8B5CF6`.
