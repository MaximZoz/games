# Звуки

Короткие UI-сэмплы из [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds)
и бросок/раздача карты (`card_play.wav`) из [Kenney Casino Audio](https://kenney.nl/assets/casino-audio)
(лицензия CC0, см. `KENNEY_LICENSE.txt`).

Голосовое `uno_call.wav` — отдельная реплика «Уно!».
`notify.wav` — тосты, новые сообщения, заявки в друзья и инвайты в игру.
`tick.wav` — секунды своего таймера хода.
`your_turn.wav` — когда очередь переходит к вам.
