Выполни деплой ветки `develop` на Fly.io.

Действуй строго по шагам:
1. Проверь, что рабочее дерево git чистое (`git status --short`).  
   Если есть незакоммиченные изменения, остановись и покажи список измененных файлов.
2. Обнови данные удаленного репозитория: `git fetch origin develop`.
3. Переключись на ветку `develop`:
   - если локальная ветка есть: `git checkout develop`
   - если локальной ветки нет: `git checkout -b develop --track origin/develop`
4. Подтяни актуальные изменения: `git pull origin develop`.
5. Запусти деплой:
   - Linux/macOS: `./launcher/deploy_cursor.sh`
   - Windows PowerShell: `.\launcher\deploy_cursor.ps1`
6. В конце выведи краткий отчет:
   - SHA текущего коммита в `develop`
   - результат деплоя (успешно/ошибка)
   - URL приложения, если он доступен из логов

Важно:
- Не запускать тесты.
- Не менять код проекта в рамках этой команды.
