# Шахматные фигуры (набор Cburnett)

SVG-фигуры — это набор **Cburnett**, тот же, что используется по умолчанию
на lichess и в Wikimedia Commons.

- Автор: Colin M.L. Burnett (User:Cburnett)
- Источник: https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces
- Лицензия: GFDL + BSD + CC BY-SA 3.0 (тройное лицензирование)

Файлы (`w_` — белые, `b_` — чёрные):
`w_king`, `w_queen`, `w_rook`, `w_bishop`, `w_knight`, `w_pawn`,
`b_king`, `b_queen`, `b_rook`, `b_bishop`, `b_knight`, `b_pawn`.
