# MultiGames

Монорепозиторий: Flutter-клиент (Web / Android / PWA) и Go API для онлайн-мини-игр.

```text
Flutter (Riverpod, go_router)
        │  REST /api/*  +  WebSocket /api/ws
        ▼
Go (net/http, pgx, JWT)
        ├── PostgreSQL — пользователи, чаты, друзья, магазин, логи
        └── Redis — лобби, партии, матчмейкинг (без Redis игры выключены)
```

Чаты и presence живут в Postgres. Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/DATABASE.md](docs/DATABASE.md).

## Что уже есть

**Аккаунт.** Регистрация и вход (email + refresh JWT), подтверждение почты, сброс пароля, OAuth Google / Apple / Yandex / VK, профиль (ник, возраст, пол, «о себе», аватар, до 3 фото). Заморозка проверяется на refresh, на каждом защищённом запросе и на WebSocket; сессии замороженного сбрасываются. Логин, регистрация, сброс пароля и подключение сокета ограничены по IP (общий счётчик в Redis, ответ `429`).

**Соцсеть.** Друзья и заявки, чаты (текст, фото, правки, ответы, блокировка), онлайн-статус, push (PWA + Android FCM). Рассылка чатов, друзей и presence, а также OAuth state, идут через Redis — несколько машин на Fly видят одно состояние.

**Партии.** Ход закрывается локом `gamelock:{id}` (в том числе ход бота), два запроса не перезаписывают доску. Список открытых лобби читается из индекса `idx:lobbies`.

**Экономика.** Монеты, ежедневная награда, магазин (смайлы, коллекции, эликсиры, рамки, ставки), инвентарь и подарки, доход коллекций, достижения и задания. Полная коллекция даёт дневной бонус: праздники и природа — 50 бронзы, космос — 1 серебро, приключения — 2 серебра, легенды — 5 серебра, драгоценности — 50 серебра. Дневной доход предмета зависит от состояния: новое 100%, потрепанное 60%, уставшее 40%, ветхое 100%, винтаж 200%. Если винтажный каждый предмет набора, бонус набора — 300%. Состояние считается от покупки: новое (7 дней), потрепанное (до 2 месяцев), уставшее (до 6 месяцев), ветхое (до года), винтаж (от года). На открытой коллекции цветная шкала показывает, между какими состояниями предмет сейчас; та же шкала есть в справке коллекций. Продать можно только новое (80% цены) или винтаж (300%): кнопка продажи в предметах остаётся, а для другого состояния открывается всплывашка с правилом и советом воспользоваться эликсиром. Эликсиры лежат в предметах и тратятся на коллекцию своего набора: омоложение на шаг новее (не новее нового), старение на шаг старше (не старше ветхого), ускорение один раз сокращает ожидание винтажа у ветхой до 3 месяцев. Винтаж эликсиром не выдаётся. После омоложения или старения отсчёт до следующего состояния начинается заново; ускорение заново ставит 3 месяца до винтажа. Цена флакона — 3% за омоложение, 7% за старение и 4% за ускорение от самого дорогого предмета набора.

**Игры** — лобби, приглашения, поиск, бот/офлайн, ставки, реванш, статистика и head-to-head:

| Игра | Режимы |
|---|---|
| Крестики-нолики | 3×3–8×8, swap, бот |
| Дурак | онлайн и офлайн с ботами |
| Морской бой | расстановка, бой, бот |
| UNO | 2–4 игрока, офлайн-боты |
| Покер (Texas Hold'em) | стол 2–6, офлайн-боты |
| Нарды | короткие и длинные, кнопка смены раскладки фишек; подсветка бара, когда сбитую шашку нужно ввести в мой ход |
| Шашки | русские, английские, поддавки, уголки; правила в диалоге — только выбранный режим; ничья без продвижения: русские и поддавки — 15 ходов каждой стороны, английские — 40, уголки — 25; звук хода, перемотка ходов, переворот доски и счёт шашек/дамок (`+N`/`−N`) в одной строке, доска на всю ширину, панель сбоку в landscape |
| Шахматы | классика 60+0, рапид 10+0, блиц 5+0, пуля 3+2 — общее время партии на каждого игрока (с прибавкой на ход) идёт и в онлайне, и в игре с ботом, показывается как `MM:SS` в системной рамке, поражение по времени; часы бота уменьшаются каждую секунду, пока он думает; на своём ходу часы партии тикают и щёлкают сразу, когда пошло моё время, но если есть ещё таймер на ход — звук только у него; цифры часов того, чей ход, красные; в статусе только «Ваш ход» / «Ход соперника», при шахе красная клетка короля; клетки последнего хода жёлто-зелёные, фигура плавно едет на новую клетку; съеденные фигуры слева, часы соперника на одной линии со статусом, перемотка справа у своих часов; после партии коротко «Вы выиграли» / «Вы проиграли», кнопки «Повторить» и «Другой соперник» над доской; пока реванш ждёт ответа, этих кнопок нет, у соперника только «Принять» / «Отклонить»; иконка — белый конь на фиолетовом фоне; салют при победе, в том числе с ботом; рокировка, взятие на проходе, превращение, ничьи (пат, мало фигур, повтор, 50 ходов, по соглашению); звук хода, переворот доски, доска на всю ширину, панель сбоку в landscape |

**Салют.** Своя победа запускает конфетти во всех играх, в том числе в партии с ботом.

**Боты.** Во всех играх с ИИ бот играет сильно и без подглядывания скрытых карт: крестики-нолики — вилки и более глубокий поиск; шашки — проходные шашки и глубокий эндшпиль, шахматы — проходные пешки и αβ-поиск; нарды — каждый ход доигрывается по всем кубикам, бот бьёт, закрывает дом и снимает шашку, чтобы не отдать марс; морской бой — плотность флота и шахматный поиск; дурак — счёт виденных карт, UNO не кормит игрока с одной картой, покер не коллирует мусор до флопа.

**Оболочка.** 29 языков, адаптив десктоп / телефон / landscape / iOS PWA, админка (пользователи, логи, поддержка), офлайн-режим по подтверждению. На карточках игр чипы режимов и кнопки одного размера.

**Геймпад** (веб: Gamepad API; Android: кнопки, стики, триггеры):

- `LB` / `RB` — вкладки меню; рамка и `A` только на точечных целях, не на нижнем меню
- левый стик и стрелки — карточки (достижения, монеты, магазин…)
- правый стик — страница или скролл
- `LT` — баланс (`A` открывает, любая кнопка закрывает окно); на «Друзья» — открыть/закрыть поиск, в том числе когда открыта клавиатура геймпада; на «Чаты» — «Новый чат»
- на «Друзья» правый стик листает вкладки (глифы RS по краям, сами табы без рамки); левый стик и стрелки — карточки; рамка как на главной появляется сразу при подключении контроллера; `A` на карточке открывает профиль; влево/вправо и `A` — кнопки «сообщение» / «удалить»; диалог «Убрать» — стик только по «Отмена» / «Убрать»
- на «Игры» правый стик влево/вправо переключает «Игры» / «Лобби» без круга (глифы RS по краям); вверх/вниз листает экран карточек страницами как смайлы, упирается в начало и конец и ставит фокус на «Создать игру» у карточки на новом экране; правила листаются стиком, закрываются кнопкой и не трогают фон; обводка ставки и баланса с отступом от монет
- на «Чаты» рамка на выбранном диалоге сразу при подключении контроллера, та же обводка что на главной; влево/вправо (левый стик, стрелки или правый стик) открывает свайп-кнопки, вверх/вниз снова выбирает чаты; в «Новый чат» клавиатура геймпада у поиска, рамка на поддержке и друзьях
- в карточке пользователя стик ходит по аватару, сообщению, крестику, статистике и коллекциям; «Ваш счёт» — отдельная строка, правый стик листает только игры, не вкладки друзей; в галерее фото и во всплывашке статистики стик скроллит список, любая кнопка закрывает, крестик без рамки; вкладки и список друзей за попапом не листаются
- в комнате чата левый стик листает сообщения и возвращает в ленту с шапки/композера; `Y` — шапка, `X` — нижняя панель (глифы Y/X, на других падах те же кнопки); `A` открывает меню сообщения или «⋯» (стрелки и стик листают пункты, любая другая кнопка закрывает); влево/вправо — ответ; `B` и «Назад» отменяют ответ/редактирование или выходят из чата; правый стик листает экран; внизу фото / поле / смайлы / отправка; панель смайлов раскрывается и сужается правым стиком, `A` отправляет, `B` закрывает
- `RT` — кнопка «Выйти» (`A` выходит)
- в магазине `A` открывает превью, затем диалог покупки (`A` купить, любая другая — только закрыть диалог); после покупки всплышка «Куплено», полноэкранный эликсир закрывается; влево/вправо с блока — иконка «i»; «Назад» только по `B`
- в предметах стик вверх листает список и не прыгает на «Назад» (`B` выходит); фокус на названии коллекции, вправо — «Подарить» / «Продать»; выбор друга как поиск в друзьях (поиск, блоки, влево/вправо — аватар и подарок); подтверждение подарка и продажи — как другие всплышки геймпада
- в партиях — курсор по полю, картам и кнопкам; в поле ввода — экранная клавиатура
- в настройках стик выделяет карточку той же рамкой со свечением, что на главной; влево/вправо (левый стик, стрелки или правый стик) — тумблер и чекбоксы той же карточки, `A` переключает; вверх/вниз или `B` снова выделяет карточку; у края списка остановка и фокус на первом или последнем; правый стик листает страницу и ставит фокус на первый или последний элемент нового экрана; `A` на языке открывает список с непрозрачной шапкой, стик листает только языки, `A` выбирает и закрывает, `B` только закрывает
- в редакторе профиля — как на входе: стик ходит по полям и кнопкам, клавиатура геймпада только по `A`, `B` скрывает, «Назад» выходит из редактирования; во всплывашке пола стик только по пунктам (`A` выбирает и закрывает); влево/вправо по фото остаются в ряду

Подсказки кнопок зависят от Xbox / PlayStation / Nintendo. В Настройках раскладка (A/B или ✕/○, LB/RB или L1/R1, LT/RT) обновляется под подключённый контроллер.

## Стек

| | |
|---|---|
| Клиент | Flutter 3.27+, Dart ≥3.2, Riverpod, go_router, 29 `.arb` |
| Сервер | Go 1.24, `net/http`, pgx, JWT, Redis, WebSocket, Web Push |
| Данные | миграции `001`–`057` |
| Деплой | Docker, Fly.io (прод + DEV), Android Play Internal |

Клиент: `client/lib/` по доменам (`auth`, `chats`, `friends`, `games`, `shop`, `core/gamepad`, `screens`).  
Сервер: `server/cmd/server`, `internal/api`, `internal/store`, `migrations/`.

## API (кратко)

Полный список: [docs/API.md](docs/API.md). Игры (`/api/games/*`, кроме `settings` / `stats`) требуют Redis.

- Auth: `/api/auth/*`, `/api/me`, `/api/profile`, `/api/profile/photos`
- Друзья, чаты, presence: `/api/friends/*`, `/api/chats/*`, `/api/presence`
- Монеты, магазин, достижения: `/api/coins/*`, `/api/shop`, `/api/inventory/*`, `/api/achievements`, `/api/tasks`
- Игры: `/api/games/{tictactoe,durak,battleship,uno,poker,nardy,checkers,chess}/*`, `/api/games/settings|stats|head-to-head|invites`
- Push: `/api/push/*`
- Админка: `/api/admin/*`
- Realtime: `GET /api/ws?access_token=`

## Быстрый старт

Нужны Flutter 3.27+, Go 1.24+, Docker.

```bash
docker compose up -d
cp .env.example .env          # и в server/.env
cd server && go run ./cmd/server
cd client && flutter run -d chrome
```

Главное в `.env`: `DATABASE_URL`, `REDIS_URL`, `JWT_SECRET`, `ADMIN_INIT_SECRET`.  
Почта — `RESEND_API_KEY` или `SMTP_*`. OAuth — `*_CLIENT_ID` / `*_CLIENT_SECRET`. Push — `VAPID_*`, на Android ещё `FCM_SERVICE_ACCOUNT_JSON`.

Без Redis сервер стартует, но лобби и партии недоступны.
